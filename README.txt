# Hanvitha Speciality Hospital — Python Website

## Run the project
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Start the website:
   `streamlit run app.py`
5. Open the local address shown in the terminal (usually http://localhost:8501).

## Demo admin login
- Username: `admin`
- Password: `hospital123`

## Included modules
Dashboard, patient registration and status updates, doctors, staff, bed management,
appointments, and billing. Data is saved locally in `hospital.db` (SQLite).

## Important safety note
This is a college demonstration project, not a real hospital information system.
Use fictional sample records only. It has a simple demo login and is not suitable
for public deployment or storing real patient/medical information. A real system
needs strong authentication, access controls, encryption, backups, audit logs,
and appropriate privacy/security review.
